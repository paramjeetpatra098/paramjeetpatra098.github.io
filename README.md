# Paramjeet Patra — Product Portfolio

A static, responsive product portfolio focused on AI/LLM, agentic AI, MCP, APIs, data products and B2B SaaS.

## Files

- `index.html` — complete portfolio
- `styles.css` — responsive styling and diagrams
- `script.js` — small interaction/animation layer
- `Paramjeet_Patra_AI_Product_Manager.pdf` — optional CV link target
- `Paramjeet_Patra_Technical_Product_Manager.pdf` — optional CV link target
- `Paramjeet_Patra_B2B_SaaS_Product_Manager.pdf` — optional CV link target

## Hosting

### GitHub Pages
1. Create a new public GitHub repository.
2. Upload all files in this folder.
3. Go to Settings → Pages.
4. Choose "Deploy from a branch".
5. Select `main` and `/root`.
6. Save. GitHub will publish the site.

### Netlify / Vercel
Upload/import the folder as a static site. No build command is required.

## Before publishing

1. Add your three final CV PDFs using the exact filenames referenced by `index.html`.
2. Replace the LinkedIn URL if your final profile URL changes.
3. Review every metric and wording against your final CV and interview-safe facts.
4. If desired, add screenshots/videos of public product work to the case studies.

## Important
The portfolio intentionally avoids confidential screenshots, customer names, internal architecture, proprietary data, or unreleased information. Add only material you are permitted to share publicly.
